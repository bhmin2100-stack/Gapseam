# GFE 1.0.2

공정 메뉴와 구조 입력을 정리하고, 내장 공정·구조 프리셋을 갱신했습니다.

- 공정·형상·증착량·실행 횟수는 진행 화면 상단에서 설정합니다. 중복된 실행 조건 버튼을 제거했습니다.
- 성장·수송, 식각·재부착, 억제, 보정 응답, 계산 정확도 메뉴는 모델에 관계없이 같은 위치에 표시합니다.
- Hole/Line 선택을 상단 형상 항목으로 옮겼습니다. 기준 폭·깊이는 입력 구조에서 가져오며 별도의 중복 입력란을 표시하지 않습니다.
- 설명 말풍선은 처음 실행할 때 꺼져 있습니다. 사용자가 저장한 설정은 유지됩니다.
- 공정·구조 프리셋과 일부 파라미터 설명을 갱신했습니다. 공정 프리셋을 적용해도 현재 구조는 유지됩니다.
- 소스 폴더의 `run_gfe.bat`은 같은 폴더의 `dist/GFE/GFE.exe`가 있으면 해당 실행 파일을 우선 사용합니다. 개발용 소스 실행은 `run_gfe.bat --source`로 선택할 수 있습니다.

`Gapseam.zip`을 새 폴더에 압축 해제한 뒤 `GFE/GFE.exe`를 실행하세요. Python 설치는 필요하지 않습니다.

`version.json`에는 배포 버전, 원본 커밋과 ZIP의 SHA-256이 들어 있습니다.
