# GFE 1.0.3

깊이에 따른 성장률을 지정하는 시험 프리셋 3개를 추가했습니다.

- **깊이 지수식 (시험)**: 깊어질수록 성장률이 감소합니다.
- **깊이 선형·지수식 (시험)**: 선형항과 지수항을 합친 경험식입니다.
- **깊이 3차식 (시험)**: 깊이의 3차 다항식으로 성장률을 지정합니다.

진행 화면의 프리셋 목록에서 선택하고 **적용**을 누르세요. 현재 구조는 유지되며, **성장·수송**에서 식 종류, 계수, 깊이 단위와 기준을 조절할 수 있습니다. 사이클·시간을 함께 불러오는 옵션을 켜지 않으면 현재 실행 횟수·시간도 유지됩니다. ALD의 GPC·사이클, CVD의 D/R·시간은 적용 후에도 바꿀 수 있습니다.

세 식은 `r=f(z)/f(0)`으로 정규화하여 GPC 또는 D/R에 곱합니다. 기본 GPC 1 Å/cycle은 비교용 값이며, 실제 공정의 측정 GPC를 뜻하지 않습니다. 두 번째·세 번째 식의 기본 깊이 단위 nm는 시험 가정입니다. 재료 물리 모델로 검증된 조건은 아닙니다. 기본 식각·재부착·억제는 꺼져 있습니다.

선형·지수식은 기본 계수·nm 단위에서 약 2.134 µm보다 깊어지면 음수가 되므로 해당 구조의 실행을 막습니다. 평탄부 대비 1,000배를 넘는 외삽도 명시적으로 중단합니다. 값을 몰래 0이나 식각량으로 바꾸지 않습니다.

수정한 계수는 사용자 프리셋과 결과 저장 파일에 함께 보존됩니다. 자세한 식과 단위는 [깊이식 사용 안내](https://github.com/bhmin2100-stack/Gapseam/blob/v1.0.3/docs/depth-formula-presets.md)를 참고하세요.

설명 말풍선을 켜면 새 계수의 도움말에서 실제 깊이식을 계산한 성장률 그래프와 계수 ±20% 비교를 볼 수 있습니다. 이 그래프는 최종 단면 예측과 구분해 표시합니다.

`Gapseam.zip`을 새 폴더에 압축 해제한 뒤 `GFE/GFE.exe`를 실행하세요. Python 설치는 필요하지 않습니다. `version.json`에는 배포 버전, 원본 커밋과 ZIP의 SHA-256이 들어 있습니다.
