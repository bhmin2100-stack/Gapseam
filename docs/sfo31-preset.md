# SFO3.1 공정 프리셋

별도 검증 조건 탭과 300–2000 Å의 8개 선택 항목을 제거하고, 일반 ‘내 조건’ 저장 목록에 SFO3.1 한 개로 통합했다. 기존 검증 조건의 이온 LOS 가림·식각·재증착 설정은 그대로 유지한다.

기본값은 누적 증착량 300 Å (150 Step × 2 Å/Step)이며 순 막 두께가 아니다. 증착량은 기존 공통 입력으로 편집할 수 있다. 프리셋 적용 시 Split은 OFF로 전환되어 한 조건만 실행하며, 사용자가 이후 명시적으로 Split을 켜는 기능 자체는 유지한다.

구조 좌표는 일반 공정 프리셋과 동일하게 저장하거나 변경하지 않는다. SFO3.1은 최초 등록 시에만 기본값으로 추가하며, 같은 이름으로 사용자가 저장한 값과 다른 프리셋은 보존한다. 일반 저장·불러오기·삭제 동작을 사용한다.

연구용 두께 비교 함수는 기존 보고서 재현용으로 유지하지만 공정 실행 UI에는 노출하지 않는다. 실제 장비에 보정된 레시피라는 의미는 아니다.
