# GFE 1.0.5

**하부 우선 ALD (시험)** 프리셋을 추가했습니다. 프리셋을 적용하면 수송·표면 반응 모델과 상부 억제를 함께 켭니다. 위쪽 성장은 상대적으로 줄이고 내부 하부가 먼저 채워지는 형상을 위한 예시입니다. 기존 구조는 유지되며, GPC와 사이클 수는 적용 후에도 조절할 수 있습니다.

기존 선형·지수식은 기본 계수에서 깊어질수록 성장률이 감소하고, Å 단위로 약 213.4 nm 아래에서 음수가 됩니다. 원식의 부호를 바꾸거나 음수를 0으로 잘라서 하부 성장으로 바꾸지 않았습니다. 원식의 안내와 음수 오류 메시지에 하부 우선 프리셋 경로를 추가했습니다.

새 조건은 매 사이클 같은 억제제·전구체 계산을 반복합니다. 식각·재부착과 폐쇄 후 내부 충전은 사용하지 않습니다. 실제 장비에 보정된 레시피나 모든 구조의 무보이드 충전을 보장하는 조건은 아닙니다. [사용 파라미터와 물리적 의미](https://github.com/bhmin2100-stack/Gapseam/blob/v1.0.5/docs/bottom-up-ald.md)를 참고하세요.

`Gapseam.zip`을 새 폴더에 압축 해제한 뒤 `GFE/GFE.exe`를 실행하세요.
