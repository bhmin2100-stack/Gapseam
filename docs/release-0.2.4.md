# GFE 0.2.4

시뮬레이션 실행 후 GIF 생성 때문에 기다리던 과정을 분리했습니다. 계산이 끝나면 결과 화면을 먼저 표시하고, 실행 이력은 전체 프레임을 그대로 보존합니다.

- 일반 실행과 Split 실행에서 GIF를 자동으로 만들지 않습니다.
- 결과창의 **GIF 저장…**에서 이미지 간격을 직접 정할 수 있습니다. 결과 화면의 이동 간격을 기본값으로 가져옵니다.
- GIF는 처음과 마지막 결과를 포함해 **최대 100장**으로 제한합니다. 저장창에 가능한 최소 간격과 저장될 장수를 표시합니다.
- 간격은 저장된 결과 이미지 기준입니다. 계산의 사이클 간격이나 정확도를 변경하지 않습니다.
- 선택한 이미지의 계산 좌표와 표시 내용은 유지하며, 저장·불러오기 JSON에는 전체 결과가 들어갑니다.
- GIF 생성 중 취소할 수 있고, 취소·저장 오류가 발생하면 기존 GIF 파일을 보존합니다.

`Gapseam.zip`을 새 폴더에 풀고 `GFE/GFE.exe`를 실행하세요.
