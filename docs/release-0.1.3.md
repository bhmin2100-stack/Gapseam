# GFE 0.1.3 · SFO3.1

- ‘내 조건’에 **SFO3.1 하나**로 통합. 기본 누적 증착량 300 Å, 적용 시 Split OFF, 현재 구조와 사용자가 저장한 값 유지.
- Conformal / Typical CVD / Etch + redeposition / Inhibition 입력과 상세 설명 정리.
- 이온 가림·재증착, 단면 평활화·수송 계산 개선 및 실제 계산 단면으로 설명 보강.
- 설명 말풍선 ON/OFF 설정과 새 GFE 아이콘 (실행 파일·창·작업표시줄).
- Git 체크아웃 줄바꿈과 Python 버전의 마지막 소수 자릿수 차이로 생긴 도움말 데이터 검증 실패 수정. 단면 좌표 일치 검사는 그대로 유지.

Windows: `Gapseam.zip`을 풀고 `GFE/GFE.exe`를 실행하세요. 개인 공정 저장 파일과 계산 결과는 배포 ZIP에 포함하지 않습니다. `version.json`은 업데이트용 SHA-256 검증 정보를 제공합니다.

검증: 전체 로컬 자동 테스트 470 passed / 18 skipped, 호환성 수정 후 도움말 데이터 테스트 68개 통과. Windows 아이콘 리소스와 업데이트 계약 확인. 실제 데스크톱 마우스 조작 및 macOS 빌드는 수행하지 않았습니다. 실제 장비로 보정된 레시피가 아닙니다.
