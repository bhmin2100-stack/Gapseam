# GFE 0.2.3

실행 이력을 파일 하나로 저장하고 다시 불러오는 기능을 보완했습니다.

- 상단 **저장 / 불러오기**와 **Ctrl+S / Ctrl+O**를 사용할 수 있습니다.
- 저장을 누르면 파일 이름과 저장 위치를 고를 수 있습니다.
- 계산에 사용한 구조, 공정·계산 파라미터, 전체 결과 이미지의 좌표와 내부 공간, 단계별 기록을 함께 저장합니다.
- 보고 있던 결과 이미지, 이동 간격, 확대·이동 위치, 식각·재부착 표시 상태를 복원합니다.
- 불러올 때 다시 계산하지 않으며, 이전 버전의 결과 JSON도 계속 열 수 있습니다.
- 파일 저장에 실패하면 기존 이력 파일을 보존하고, 손상된 이력 파일은 현재 결과를 지우기 전에 확인합니다.

결과창에서 저장하는 값은 해당 결과를 계산할 때 사용한 조건입니다. 실행 후 입력란에서만 바꾼 값은 기존 결과의 조건을 덮어쓰지 않습니다. 구조는 계산에 사용한 최종 입력 단면으로 복원됩니다.

`Gapseam.zip`을 새 폴더에 풀고 `GFE/GFE.exe`를 실행하세요.
