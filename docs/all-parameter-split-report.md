# 전체 공정 파라미터 단일 값 비교 (2026-10-03)

## 범위와 결과

- 실제 공정·수치·진단·미사용 호환 입력 72개: 각 Split 내부에서 필드 하나만 변경.
- 고유 계산 197개 실행, 보고서에 기본/선택 조건 173개 포함.
- 기본 최종 경계 차이가 10 Å 미만인 4개 항목은 고정 조합 4개씩 추가 시험. 모두 기존보다 차이가 커졌음.
- 추가 조합은 시험 범위에서 최대 차이를 보인 조건이며 전역 최적화나 실측 장비 검증을 뜻하지 않음.
- 별도 화면·편집·선택 조절 항목 31개는 역할과 계산 관계를 목록으로 점검. 초기 구조 편집·초기 평활화는 공정 파라미터 Split 대상이 아님.

| 항목 | 기본 차이 Å | 추가 조합 차이 Å |
|---|---:|---:|
| 재증착 분포 폭 | 8.276 | 81.263 |
| 계산 이온 방향 수 (수치 근사) | 3.379 | 26.983 |
| 억제 성장률 평활화 (수치 설정) | 5.804 | 21.122 |
| 기존 이온 입구 가림 | 3.522 | 7.303 |

## 검증

`experiments/validate_all_parameter_splits.py`가 160개 기본/선택/추가 비교 시나리오에서 한 필드 변경과 경계 거리 재계산을 검증함. 보고서 173개 계산의 좌표가 실제 캐시 좌표와 일치하고, Step 순서·마지막 Step·유한 좌표를 확인함. CVD 상부 성장, 재증착 분포 폭, 닫힘 후 채움, 닫힘 진단의 4개 대표 조건을 새로 실행해 모든 저장 프레임의 단면·폐공간을 대조함.

브라우저에서는 단면 나란히/겹치기/확대/기록된 재증착 원료 경로, 타임라인, 기본/추가 조합 전환, 모바일·데스크톱 배치를 확인. GFE 엔진이나 프로그램 실행 파일은 이 요청에서 변경하지 않음.

## 재현과 산출물

저장소 루트에서 실행:

```powershell
$env:PYTHONUTF8='1'
& .venv/Scripts/python.exe experiments/build_all_parameter_splits.py
& .venv/Scripts/python.exe experiments/validate_all_parameter_splits.py --complete
```

생성 위치: `experiments/all-parameter-split-20261003/`.
캐시와 `verification.json`에 실제 계산·검증 기록을 보관. report-app은 공용 보고서 런타임을 사용하며 데이터 출처를 각 비교에서 확인할 수 있음. 휴대용 HTML은 검증된 분리 빌드에서 공식 export-offline으로 내보냄.

검증 수치는 현재 경험식 엔진의 민감도이며 회사 실측 데이터나 비밀 장비 조건은 포함하지 않음. 계산 시간은 각 조건의 단발 측정으로 성능 벤치마크가 아님.
