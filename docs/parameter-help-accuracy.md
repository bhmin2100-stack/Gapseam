# 설명 말풍선 정합성 점검 (2026-10-03)

대상은 GFE 기본 통합 모델의 **코드 구현과 설명 사이의 정합성**이다.
실측 막질, SEM 또는 장비 레시피와의 물리적 보정을 완료했다는 뜻은 아니다.
이번 변경은 도움말과 테스트에 한정하며 시뮬레이션 엔진 동작은 변경하지 않는다.

## 수정한 차이

| 항목 | 실제 구현 및 수정 내용 |
| --- | --- |
| 재증착 분포 폭 | 원료별 방출 축 하나로 도착점을 찾은 뒤, 거리×tan(각도)로 측벽 주변 분배 폭을 정한다. 여러 방출 광선으로 그렸던 애니메이션 제거. |
| 재증착률 | 전체 제거량이 아니라 유효 도달 원료량에 곱하는 예산이다. 탈출 원료는 제외한다. |
| 재증착 ON/OFF | OFF이면 새 이온 가림 경로도 OFF가 된다. 가림을 유지하고 재부착만 없애려면 재증착·이온 가림 ON, 재증착률 0%를 사용한다. |
| 재증착 방향 | 법선과 수직 입사 반사축의 혼합. 음수는 외삽이며 깊이 이동 방향을 일률적으로 단정할 수 없다. |
| CVD | 실제 `typical_cvd.growth_ratios`를 사용한다. 상부 영향 길이는 깊이뿐 아니라 모서리의 좌우 범위에도 작용한다. |
| 기존 최소 증착률 | `floor + (1-floor)*raw`이며 `max(floor,raw)`가 아니다. |
| 억제 | 피복 억제·재결합·바닥 보강을 결합한다. 강도 0%가 전체 모델 OFF는 아니다. CVD ON에서도 억제 재결합은 기존 감쇠 계수에 의존한다. |
| 기존 이온 전달 하한 | 깊이 감쇠와 기하학적 보정을 곱한 **뒤** 하한 적용. 새 LOS 경로에는 미적용. |
| 입사 방향 수 | 정규화한 각도 적분의 표본 수. 물리적 이온 수나 총 입사량 증가가 아니다. |
| 기준 치수 | 기준 폭·깊이·길이를 바꿔도 초기 구조 좌표 자체는 변하지 않는다. Line 길이 0은 무한 길이 근사. |
| 닫힘 진단 간격 | 진단 기록에 쓰이며 실제 접촉 또는 잔류 채움 시작을 앞당기는 조건이 아니다. |
| 잔류 채움 | 최초 폐공간 면적에 대한 **총 예산**. 매 Step 비율이 아니다. 잔류 감쇠 길이는 후보 총량 적분의 공간 가중치이고, 실제 채움은 예산 내 균일 오프셋 축소다. |
| 식각 평활화 | 법선·수율·이동/방출 방향에도 작용한다. 통합 재증착 경로에서는 단면 완화도 수행한다. |
| 표시·좌표 | 결과 프레임을 무조건 두꺼워지는 막으로 그리지 않는다. X 셀은 좌우, Y 셀은 상하 이동만 표시한다. |

## 단면 애니메이션으로 개선한 범위

- 응답 곡선과 처리 순서 상자 대신, **52개 공정·계산 항목의 두 조건을 실제 엔진으로 실행한 트랜치 단면**을 보여준다. 공통 조건을 재사용한 고유 실행은 95개다.
- `단면 비교`: 두 조건의 계산된 Step별 단면을 같은 X/Y 축척으로 나란히 재생한다. 색 영역은 추가된 막, 회색 점선은 초기 단면, 흰 내부는 빈 공간이다. 프레임 사이에 임의 형상 보간을 하지 않는다.
- `변화 확대`: 최종 경계 표본 차이가 가장 큰 위치를 공통 좌표·축척으로 확대한다. 표시 수치는 양방향 꼭짓점-선분 거리의 최대 표본값이며 연속 경계의 엄밀한 Hausdorff 거리라고 주장하지 않는다. 폐공간 경계도 비교한다.
- `물리 의미`: 트랜치 안의 실제 위치에서 성장 방향, 이온의 첫 충돌, 재증착 이동과 도착 분포, 잔류 공간, 계산용 표면 점 등을 보여준다. 재증착 선·식각/부착 위치는 엔진이 기록한 자료를 사용한다. 설명용 점 크기·속도·성장 화살표는 실제 입자 수·속도·막 두께가 아니라고 표시한다.
- `자동 재생`은 단면 비교 → 변화 확대 → 물리 의미를 순환한다. 개별 보기 선택과 일시정지도 가능하다. 네이티브 클릭 시 닫히던 Qt 기본 툴팁 대신 비활성화 도구 창을 사용한다.
- 그림은 **미리 계산한 고정 예시 레시피**이며 현재 사용자의 입력·구조로 실행한 결과가 아니다. 현재 값, 예시 두 값, 예시 레시피, 현재 모델 적용 여부를 분리해 표시한다. 꺼진 기능의 예시를 보여주더라도 현재 미적용임을 표시한다.
- 대상 항목만 바꾼다. 식각·재증착 체크박스가 다른 기능을 함께 끄는 경우에는 실제 UI의 연동 규칙도 똑같이 적용하고 이를 고지한다.
- 좌표·표시·결과 프레임 등 비공정 항목은 공간적 의미를 그린다. 결과 프레임 도움말은 저장된 계산 결과가 있으면 그 결과를 사용하며, 없으면 결과가 없음을 표시한다. 닫힘 진단 간격은 고정 형상과 진단 기준선으로 설명하며 가짜 막 성장을 만들지 않는다.
- 도움말 열기·재생은 공정값, 초기 구조, 저장 결과를 바꾸지 않는다. 마우스를 올릴 때 전체 시뮬레이션을 실행하지 않는다.

### 자료 재생성 및 배포

`experiments/build_help_trench_movies.py`가 실제 엔진 결과를
`src/gapsim/emulation/help_trench_examples.json.gz`로 만든다.
엔진 소스 해시와 각 실행의 전체 설정을 저장하고, 검사에서 오래된 자료를 검출한다.
PyInstaller와 Python 패키지 모두 이 자료를 포함한다.
`experiments/render_help_trench_review.py`는 그림의 별도 검토 이미지를 생성한다.

## 회귀 검사

`tests/test_parameter_help_response.py`: 실제 엔진 함수와 출력 대조, OFF/0%/하한,
CVD·억제 결합, 숨은 감쇠 의존성, 기준 구조 고정, LOS 및 재증착률 0%,
잔류 채움 예산, 큰 Step 값에서의 작업량 제한.

`tests/test_parameter_help.py`: 모든 도움말 표시·애니메이션, 현재 값 갱신,
모델 상태와 편집 상태 구분, 읽기 전용 보장, 기존 설정 ON/OFF 동작 유지,
세 가지 보기의 렌더링과 마우스 클릭 시 말풍선 유지.

`tests/test_parameter_help_trench.py`: 52개 항목 포함 여부, 엔진 해시, 전체 설정,
계산 프레임·공통 축척·첫 충돌·재증착 경로·폐공간 비교.
대표 7개 파라미터의 두 값을 새로 시뮬레이션해서 저장된 모든 표본 프레임의
단면 및 폐공간 좌표가 정확히 일치하는지 검사한다.

### 확인 결과

- 도움말·단면 집중 검사: **94 passed**, 17.14초.
- 첫 단면 배포판에서 Windows의 CVD 상부 성장 도움말을 F1로 열고 Step별 실제 단면 재생을 확인했다. 이어서 네이티브 클릭 시 말풍선이 닫히는 문제를 발견해 수정했다.
- 최종 전체 자동 검사: **467 passed, 18 skipped**, 98.23초.
- 수정 배포 빌드: `dist/help-trench-interactive-20261003/GFE/GFE.exe` 성공. 기존 실행 파일과 이전에 열려 있던 창은 보존했다.
- 이 수정 EXE를 Windows에서 실행해 CVD 상부 성장의 F1 열기, 단면 재생, 변화 확대, 물리 의미, 일시정지 유지, 재생 재개, Esc 닫기를 직접 조작해 확인했다. 보기 버튼을 눌러도 창이 유지된다.
- 같은 EXE에서 재증착 분포 폭의 3°/35° 실제 단면 비교, 8.28 Å 경계 표본 차이의 공통 위치 확대, 실제 원료 경로·부착 분포 그림을 확인했다. 자동 재생 말풍선을 열어 두었다.
- 모든 파라미터를 실제 마우스로 하나씩 검사한 것은 아니다. 전체 항목 표시는 자동 검사, 대표 항목은 실행 화면 검사로 구분한다.
- Git 커밋/푸시는 수행하지 않았다. Continuum 게시 도구와 연결된 Supabase 저장 경로가 없어 Hub 기록을 갱신하지 못했다.
