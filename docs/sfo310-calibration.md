# SFO3.10 공정 프리셋

SFO3.10은 SFO3.1을 바꾸지 않고 추가한 ALD 공정 모델이다. 공정 프리셋에서 SFO3.10을 선택한 뒤 **파라미터 적용**을 누른다. 구조는 별도로 선택하며 적용할 때 기존 cycle 수를 유지한다. 기본 GPC는 0.56 Å/cycle이다.

이 모델은 구조의 깊이/입구 폭과 누적 증착량에 따른 성장 응답, 폐쇄 깊이에 따른 충전 한도, 깊은 void부터 충전 예산을 배분하는 경험식을 사용한다. 폐쇄 이후에도 남은 예산 범위에서 void가 줄어들 수 있다. 이는 형상 정합을 위한 모델이며 폐쇄 후 실제 물질 전달이나 물성에 대한 독립적인 검증은 아니다. 다른 구조와 조건에 대한 예측력도 별도 확인이 필요하다.

사용자가 확인한 4 Å 간격 연구 결과에서는 기존 구조 300 Å에서 하부 통로 최소 폭이 약 20.9 nm였고, 새 구조 600 Å의 void 폭은 약 8.4 nm였다. 새 구조 600 Å의 void 위치와 면적까지 실측과 완전히 일치한 것은 아니다.

**다음 Depo**는 결과 형상을 출발점으로 하는 별도 공정 단계다. 3.10의 누적 증착량과 폐쇄 후 충전 예산은 다음 단계로 전달되지 않으므로 같은 조건을 중간에 나눠 실행한 결과는 하나의 연속 계산과 같다고 보장할 수 없다. 연속 증착 형상을 확인하려면 원하는 총 cycle을 한 번에 계산한다.
