# GFE 0.2.2

결과 이미지의 이동 간격과 시점별 증착량 표시를 추가했습니다.

- 이동 간격을 1·2·3·5·10·100장 중 선택할 수 있습니다.
- 이전·다음 버튼, 슬라이더 방향키와 자동재생에 같은 간격이 적용됩니다.
- 마지막 이미지는 간격과 관계없이 표시하며, 드래그로 개별 이미지를 선택할 수 있습니다.
- 선택한 시점까지의 기준 평면 누적 증착량을 Å로 표시합니다. 저장된 결과의 사이클·시간·증착량을 사용합니다.
- Split 비교창에도 이동 간격과 조건별 증착량을 표시합니다.

증착량은 공정의 기준 평면 입력량입니다. 트렌치 내부의 위치별 실제 막 두께와는 다릅니다. 예전 연속 공정 파일에 누적 정보가 없거나 성장 기준이 서로 다르면, 확인 가능한 현재 단계의 양 또는 기록 없음으로 표시합니다.

GitHub의 소스 ZIP 대신 아래 `Gapseam.zip`을 내려받아 새 폴더에 풀고 `GFE/GFE.exe`를 실행하세요.
