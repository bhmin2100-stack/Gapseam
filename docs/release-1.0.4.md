# GFE 1.0.4

깊이 선형·지수식과 깊이 3차식 시험 프리셋의 기본 z 단위를 nm에서 Å로 수정했습니다. 내장 프리셋을 다시 선택하고 **적용**하면 Å가 들어갑니다. 현재 구조와 사이클 수는 기존 적용 옵션을 따릅니다.

성장·수송의 설명은 현재 선택한 단위를 표시합니다. 이전에 nm로 저장한 사용자 프리셋과 결과는 nm로 유지합니다. 깊이 지수식은 이미 Å 기반 원식과 같은 계산이므로 결과가 바뀌지 않습니다.

기본 계수와 Å 단위에서 선형·지수식은 약 213.4 nm 아래에서 음수가 되며, 3차식은 400 nm에서 평탄부 대비 약 71배로 커집니다. 음수나 평탄부 대비 1,000배를 넘는 성장률은 기존과 같이 실행을 중단합니다. 음수를 0으로 자르거나 계수를 자동으로 바꾸지 않습니다.

성장률은 계속 `GPC 또는 D/R × f(z)/f(0)`으로 계산합니다. 원식 y의 절대 단위와 실측 유효 범위는 별도 확인이 필요합니다. 자세한 내용은 [깊이식 사용 안내](https://github.com/bhmin2100-stack/Gapseam/blob/v1.0.4/docs/depth-formula-presets.md)를 참고하세요.

`Gapseam.zip`을 새 폴더에 압축 해제한 뒤 `GFE/GFE.exe`를 실행하세요. Python 설치는 필요하지 않습니다.
