# GFE 0.1.2 · SFO3.1

- 별도 검증 프리셋을 ‘내 조건’의 **SFO3.1 한 개**로 통합했습니다. 기본 누적 증착량은 300 Å이며 적용 시 Split을 끕니다. 현재 구조와 사용자가 저장한 수정값은 유지합니다.
- Conformal / Typical CVD / Etch + redeposition / Inhibition 공정 입력을 정리했습니다.
- 이온 가림과 재증착, 단면 평활화·수송 계산 개선을 포함합니다. 실제 장비로 보정한 모델은 아닙니다.
- 모든 조절 항목의 설명과 실제 계산 단면 예시를 보강했습니다. 상단 설정에서 말풍선을 켜고 끌 수 있습니다.
- 트랜치·증착층을 표현한 새 GFE 아이콘을 실행 파일, 창, 작업표시줄에 적용했습니다.

Windows: `Gapseam.zip`을 풀고 `GFE/GFE.exe`를 실행하세요. 개인 공정 저장 파일과 계산 결과는 ZIP에 포함하지 않습니다. `version.json`은 업데이트용 SHA-256 검증 정보를 제공합니다.

검증: 전체 자동 테스트 470 passed / 18 skipped. 버전 변경 후 업데이트·아이콘·SFO3.1 관련 24개 테스트도 통과했습니다. Windows 실행 파일 빌드 및 아이콘 리소스를 확인했습니다. 실제 데스크톱 마우스 조작 검증과 macOS 빌드는 이번 배포에서 수행하지 않았습니다.
