# GFE 공정 파라미터 개편 (2026-10-03)

## 사용 구조

진행 화면의 네 버튼은 설정 페이지를 선택한다. 페이지 이동은 공정을 켜거나 끄지 않는다.
공정 적용 상태는 공통 상태줄에 항상 표시된다. 기본 증착량과 step 수는 모든 조합에 공통이다.
순수 Conformal 버튼만 CVD/기존 depletion/Etch/Inhibition을 명시적으로 OFF한다. 수치와 구조는 유지한다.

| 분류 | 주 조절값 | 판단 및 변경 |
|---|---|---|
| Conformal depo | Å/step, step 수, 누적 명목 Å/nm | 유지. 실제 ALD 사이클·시간·순 막 두께와 구분 |
| Typical CVD | Overhang %, Cusping %, Bottom 성장률 %, 상부 영향 길이, 곡선 지수 | 신규 경험식. 3가지 경향을 독립 조절하고 Split 대상에 추가 |
| Etch + redeposition | 식각량, 각도 응답, 이온 가림, σ, redep 효율·퍼짐·방출 방향 | 기존 구현 및 300–2000Å 검증 프리셋 보존. 관련 곡선과 프리셋을 같은 그룹에 배치 |
| Inhibition | 억제 강도·침투 깊이·최저 성장·곡선 | 유지. CVD와 조합 가능. Bottom boost/recombination은 경험적 보정임을 구분 |
| 수치 설정 | 점 간격·각도 수·평활화 | 물리 파라미터와 명칭을 구별. 해상도/곡선 편집은 펼쳐서 사용 |
| 기존 depth/ion 감쇠 | 기존 계수 및 곡선 | 호환 용도로 유지. 새 CVD/입사 가림 적용 시 비활성화하며 값은 보존 |
| 고정 source 선택·Soft LOS | 현재 통합 경로에서 조절 불가/효과 없음 | 기존 숨김 유지. 동작하지 않는 조절기를 새 주 화면에 노출하지 않음 |
| LF proxy·closure proxy·reflected ion | 통합 엔진에서 지원하지 않는 과거 항 | 데이터 호환 위해 제거하지 않음. 기존 비활성 상태 유지 |

## Typical CVD의 의미와 한계

중성종 수송 연구 코드(cvd_transport.py)는 유지한다. 이번 실사용 패널은 그 고비용 수송 해석을
몰래 대체하거나 동일 물리라고 주장하지 않는다. 입력된 2D 중심 feature에 대한 양의 법선 성장
경험식으로 현상 민감도를 빠르게 비교한다. 실제 온도·압력·유량·sticking 계수로 보정한 모델이 아니다.

기본 성장률 b(z)=1−(1−B)·min(1,z/D)^p.
상부 가중치 U=exp(−(z/L)^2), 어깨 가중치 S=exp(−((|x−xc|−W/2)/L)^2).
최종 성장률 = b(z)·[1+O·U·nx²+C·U·S·4nx²ny²].

- B=Bottom %/100, O=Overhang %/100, C=Cusping %/100.
- D/W는 공유 기준 깊이/폭, L은 상부 영향 길이. 깊이는 구조 입력에서 갱신되지만 폭은 설정값이므로
  `현재 구조에서 폭·깊이 가져오기` 버튼으로 단일 트랜치의 입구 폭을 맞추거나 직접 입력한다.
- Overhang은 상부 측벽, Cusping은 어깨 부근 경사면의 성장 강화. 최종 형상 치수의 보장값 아님.
- Bottom %는 기준 깊이에서의 기본 성장률이며 inhibition이나 상부 강화 이전 값.
- CVD ON이면 기존 depth 감쇠를 중복 적용하지 않는다. Inhibition은 성장률에 곱한다.
- 양의 증착만 수행하며 sputter/redep 원료를 생성하지 않는다. Etch 단계는 별도로 유지한다.
- 닫힌 void는 보존하고 과거 잔류 fill proxy를 새 CVD에 적용하지 않는다.
- 상부 강화의 최대 배율을 고려해 수치 substep을 늘린다.
- 여러 trench, 비대칭 feature, 실측 물성, RF/플라즈마/화학반응 정확도는 별도 검증 필요.

일반적인 CVD 형상 해석은 입사 플럭스·sticking·재방출·반응률의 결합과 실측 보정이 필요하다.
참고: [TU Wien, Deposition Models](https://iue.tuwien.ac.at/phd/holzer/node97.html).
문헌의 수치는 이 경험식의 검증값으로 사용하지 않았다.

## 데이터 및 검증

새 필드는 설정, 결과 JSON, 내 프리셋, 재생, 캐시 키에 포함된다.
이전 JSON/프리셋에 새 필드가 없으면 CVD OFF로 읽는다. 검증 이온 프리셋도 CVD OFF이다.
tests/test_process_parameters.py는 양의 성장·대칭·유효 범위·실제 단면 변화·기존 결과 불변·복합 공정·UI 저장/복원을 검사한다.
실제 장비 막질의 정량 검증을 대체하지 않는다.

## 파라미터 이름과 움직이는 도움말

화면 이름은 `상부 성장`, `모서리 성장`, `바닥 성장률`, `식각량`, `이온 각도 폭`,
`재증착률`, `억제 깊이`처럼 짧게 표시한다. 전문 용어와 뜻은 도움말 안에 둔다.
입력칸 또는 항목 이름에 약 0.65초 마우스를 올리거나 입력칸에서 F1을 누르면 말풍선이 열린다.

- 현재 값, 쉬운 설명, 낮출 때/높일 때 영향, 적용 조건과 한계를 함께 표시한다.
- 단면 성장, 이온 이동, 재증착 이동, 각도·깊이 곡선, 계산 점 간격을 움직이는 벡터 그림으로 설명한다.
- 그림은 개념도다. 현재 구조나 설정을 계산한 결과가 아니며 정량 예측에 사용하지 않는다.
- `일시정지`/`재생`, Esc 닫기를 지원한다. 말풍선 안으로 마우스를 옮겨 읽을 수 있다.
- 비활성 입력값에도 도움말을 제공한다. 클릭/스크롤/페이지 이동은 기존 기능을 유지한다.
- 도움말은 설정·결과를 변경하거나 엔진을 실행하지 않으며, 숨겨지면 애니메이션 타이머를 정지한다.
- 작은 화면에서는 본문을 스크롤하고, 다중 모니터에서는 해당 화면 안으로 위치를 제한한다.

`tests/test_parameter_help.py`에서 설명 연결, 비활성 입력, F1/Esc, hover 지연, 타이머,
일시정지, 화면 경계, 각 그림 렌더링 및 설정 불변을 검사한다.

### 전체 조절 항목으로 확장

공정 패널 외에도 구조/스무딩, Split 시작·끝·간격, Compare 선택, 프리셋, 이미지와
결과 표시, 메모, 애드온 체크 목록, 별도 Split/Compare 결과 창에 설명을 연결한다.
구조 표에서는 X/Y 셀에 맞는 방향과 값을, 곡선에서는 각 조절점에 연결된 파라미터를 설명한다.
조절점을 끄는 동안에는 말풍선을 열지 않는다. 표시·이름 설정에는 물리적 성장 그림 대신
표시/선택 개념도를 사용하며, 통합 모델에서 쓰지 않는 호환 필드는 효과 없음으로 명시한다.

모든 내장 입력 위젯을 숨김/비활성 상태까지 검사하여 전용 설명 누락을 검출한다.
추후 추가되는 확장 입력은 기본 안내를 제공하되 검증되지 않은 물리적 영향을 추정하지 않는다.
