# GFE 1.0.1

공정 프리셋을 추가하고 긴 계산 결과를 탐색할 때의 반응 속도를 개선했습니다.

- 새 보정 공정 프리셋을 추가했습니다. 공정값을 적용해도 입력 구조는 유지되며 사이클 수를 직접 수정할 수 있습니다.
- 결과 이동 간격을 원하는 양의 정수로 입력할 수 있습니다. 저장 이력을 불러올 때도 해당 간격을 복원합니다.
- 결과 슬라이더를 드래그하는 동안 매 프레임을 그리지 않고, 놓은 위치의 정확한 결과를 표시합니다.
- 긴 증착·식각 결과의 표시 방식을 개선해 화면 탐색의 계산 부담을 줄였습니다. 저장된 시뮬레이션 결과는 바꾸지 않습니다.
- 공정 프리셋 화면의 문구를 정리하고 증착량 기준을 식각·재부착 맨 위로 이동했습니다. 시뮬레이션 실행 버튼을 초록색으로 표시합니다.

`Gapseam.zip`을 새 폴더에 압축 해제한 뒤 `GFE/GFE.exe`를 실행하세요. Python 설치는 필요하지 않습니다.

`version.json`에는 배포 버전, 원본 커밋과 ZIP의 SHA-256이 들어 있습니다.
