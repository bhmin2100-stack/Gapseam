# 깊이식 시험 프리셋

세 프리셋은 서로 별개의 경험식입니다. 표면 법선 이동과 형상 교차·폐쇄 계산은 GFE 엔진을 사용하고, 위치별 성장률만 아래 식으로 지정합니다. 반응확률·노출량·플라즈마 에너지를 풀어서 얻은 재료 물성 모델은 아닙니다.

## 적용과 증착량

1. 진행 화면의 프리셋에서 식을 선택하고 적용합니다. 구조는 바뀌지 않습니다.
2. 성장·수송에서 계수, 깊이 단위, 깊이 기준을 확인합니다.
3. ALD는 측정 GPC와 사이클 수, CVD는 측정 D/R과 시간을 지정합니다.
4. 시뮬레이션을 실행합니다. 사용자 프리셋 저장 및 결과 저장·불러오기에서 식과 계수도 보존됩니다.

기본값은 ALD, GPC 1 Å/cycle, 식각 전 증착량, 식각·재부착·억제 OFF입니다. 내장 실행 길이는 550사이클이지만, 사이클·시간 함께 불러오기 옵션이 꺼져 있으면 기존 사이클·시간이 유지됩니다. **1 Å/cycle은 비교용 설정이고 실제 공정의 GPC로 추정한 값이 아닙니다.**

깊이식의 출력 단위가 확정되지 않았으므로 절대 증착량으로 직접 해석하지 않습니다. `r=f(z)/f(0)`을 사용하여 깊이 0의 성장률을 1로 만들고, ALD에서는 GPC, CVD에서는 D/R에 곱합니다. 원식의 전체 배율 D는 정규화에서 소거됩니다. 식각을 추가할 때는 기존 GFE의 식각 전/기준면 순성장량 보정 규칙이 적용됩니다.

## 식과 단위

`d`는 기준면 아래로 양의 깊이, `z=-d`입니다. 기본 기준면은 실행 시작 시 구조의 최고 상면입니다. 현재 상면을 선택하면 각 계산 단계의 최고 표면 높이를 기준으로 합니다. 기준면 위쪽은 깊이 0으로 처리합니다.

| 프리셋 | 기본 정규화 전 식 | 단위와 동작 |
|---|---|---|
| 깊이 지수식 | `r(d)=exp(-0.000829*d_nm)` | 양의 깊이 nm, 감쇠계수 1/nm. 원식의 음수 z 기반 AR 해석에 해당합니다. |
| 깊이 선형·지수식 | `f(z)=0.0001*z+0.2134+0.0282*(1-z/100)*exp(z/100)` | 기본 z는 음수 nm, `f(0)=0.2416`. 깊이 약 2134 nm에서 0을 지납니다. |
| 깊이 3차식 | `f(z)=-6e-10*z^3-6e-7*z^2-0.0002*z+0.423` | 기본 z는 음수 nm, `f(0)=0.423`. 기본 계수에서 깊은 곳의 성장률이 크게 증가합니다. |

지수식 원식의 `k=-0.0000829*TopCD_A`, `x_AR=-d_A/TopCD_A`, `m=0`, `p=1`을 대입하면 CD가 소거되어 위 식이 됩니다. 양의 AR에 음의 k를 그대로 넣으면 증가식이 되므로 이 프리셋의 해석과 다릅니다. D=2.416도 정규화에서 소거되므로 GPC로 자동 적용하지 않습니다.

선형·지수식과 3차식은 nm/Å를 선택할 수 있습니다. **단위를 바꿔도 계수는 자동 변환하지 않으며, 같은 숫자 z의 물리적 깊이를 바꿉니다.** 따라서 원식의 단위를 확인해서 선택해야 합니다. nm 가정은 실험적으로 확정된 정보가 아닙니다.

## 계산과 범위 검증

식은 ALD 사이클 또는 CVD 시간 단계 안에서도 표면이 이동할 때마다 다시 계산합니다. 성장 간격은 최대 성장 간격과 표면 점 간격을 기준으로 세분합니다. 표면이 닫혀 생긴 보이드 안에 성장량을 계속 공급하지 않습니다.

실행 전 구조의 전체 깊이 구간에서 끝점과 내부 극값을 검사합니다. 계산 중에도 성장률을 검사합니다.

- `f(0)<=0`, 음수 성장률, 유한하지 않은 값은 오류로 알립니다. 음수를 식각으로 간주하거나 0으로 자르지 않습니다.
- 평탄부의 1,000배를 넘는 성장률은 미검증 외삽을 막는 수치 가드입니다. 물리적 한계를 뜻하지 않으며, 값 자체를 1,000으로 자르지 않습니다.
- 기본 3차식은 5 µm에서 평탄부 대비 약 145.2배입니다. 계산 가능하다는 사실이 그 범위의 실측 적합성을 보장하지 않습니다.
- 기본 선형·지수식은 5 µm 구조에서 음수가 되므로 실행할 수 없습니다. 적용 깊이가 맞는 별도 식이나 검증된 계수를 사용해야 합니다.

기존 프리셋은 기존 모델 경로를 사용합니다. 새 깊이식은 선택할 때만 활성화됩니다.
