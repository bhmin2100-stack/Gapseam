# GFE 0.2.5

결과창의 **GIF 저장…** 속도를 개선했습니다. 저장한 계산 결과에서 이미지를 만들며 증착 계산을 다시 실행하지 않습니다.

- 각 이미지를 PNG로 압축한 뒤 다시 풀던 중간 변환을 제거했습니다.
- GIF 준비 단계에서 마지막 결과를 불필요하게 먼저 그리던 작업을 줄였습니다.
- 식각 이력을 구성할 때 연속한 두 단계가 공유하는 표면 도형을 재사용합니다.
- 사용자가 지정하는 이미지 간격, 처음·마지막 결과 포함, 최대 100장 제한은 유지합니다.
- 기존 버전과 GIF 이미지·파일 일치 및 원본 결과 보존을 확인했습니다. 출력 해상도는 1820×1040으로 유지합니다.

`Gapseam.zip`을 새 폴더에 풀고 `GFE/GFE.exe`를 실행하세요.
