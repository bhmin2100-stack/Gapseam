# GFE 0.2.6

깊거나 표면이 긴 구조에서 계산을 시작하기 전에 해상도를 선택할 수 있습니다.

- 표면 길이와 현재 점 간격으로 예상 내부 점 수를 계산합니다. 10,000개를 넘으면 **계산 해상도 선택** 창을 표시합니다.
- **현재 유지 / 권장 / 더 빠르게** 중에서 선택할 수 있으며 각 간격을 Å·nm와 예상 점 수로 보여줍니다. 권장 간격은 약 6,000개, 더 빠른 간격은 약 3,000개를 목표로 제안합니다.
- 큰 구조도 이미 충분히 넓은 간격으로 설정되어 있으면 불필요하게 팝업을 띄우지 않습니다.
- 확인한 선택만 이번 실행 조건에 반영합니다. 취소하면 기존 설정과 결과를 보존합니다. 저장된 공정 프리셋은 변경하지 않습니다.
- 일반 실행·이어 실행·Split 실행에 적용합니다. 큰 구조의 자동 미리보기는 실행 버튼에서 선택할 때까지 기다립니다.
- 실행 중 실제 내부 점 수를 표시하여 입력 점 수와 구분할 수 있습니다.

간격을 넓히면 계산량이 줄지만 팁·목 폭·모서리 형상이 달라질 수 있습니다. 예상 점 수는 실행 시간이나 정확도를 보장하지 않으며, 정밀한 최종 비교에는 기존 간격으로 재검증하세요.

`Gapseam.zip`을 새 폴더에 풀고 `GFE/GFE.exe`를 실행하세요.
